# Security policy

## Reporting a security issue

Please do **not** report a security issue in a public issue, pull request or
discussion. Report it privately through GitHub's private vulnerability
reporting:

1. Open the repository's [security page](https://github.com/biafra23/myotis/security)
   and click **Report a vulnerability**, or go straight to the
   [new advisory form](https://github.com/biafra23/myotis/security/advisories/new).
   You need to be signed in to GitHub.
2. Describe the issue: the affected component (engine, platform, version or
   commit), how to reproduce it, and what an attacker gains (for example, a
   way to make the node accept unverified data).
3. Submit. Only you and the maintainer can see the report. The discussion
   stays in that private advisory, and the advisory is published once a fixed
   release is out.

Wallets built on Myotis, such as [Punicus](https://github.com/biafra23/punicus),
have their own repositories. A security issue that lies in the wallet rather
than in the engine is reported to that wallet's repository, privately as well
(Punicus takes reports through its own
[new advisory form](https://github.com/biafra23/punicus/security/advisories/new)).
