# Ideas

Proposals, evaluations and research that are **not built**, or of which only a first slice
exists (the document's status line says which). Nothing here describes shipped behaviour.
When an idea is built, its document moves to [design-history](../design-history/) and the
behaviour gets a page in [how-it-works](../how-it-works/). Index:
[documentation index](../README.md#ideas).
