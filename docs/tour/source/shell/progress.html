Your offline library

Two kinds of book work without a network: your own ebooks, and the Rust documentation that rustup installs with every toolchain. When this page was built on a machine with those docs, the links below open the local copies; otherwise they point to doc.rust-lang.org. If a link doesn't open, run rustup doc --book (or --std, --rust-by-example, --nomicon) in a terminal. It opens the same pages from whichever toolchain is current.

  • The Rust Programming Languagelocal copy offline The current edition. Chapter numbers here follow it: 4 ownership, 10 generics, traits and lifetimes, 15 smart pointers, 16 concurrency, 17 async, 18 trait objects, 19 patterns, 20 unsafe code and macros.
  • Rust by Examplelocal copy offline Short runnable pages. “Scoping rules” (RAII, moves, borrowing, lifetimes) is the memory-model core.
  • The standard library docslocal copy offline For the exact types this code uses: Arc, Mutex, atomics, CString, Future. The search box works offline too.
  • The Rustonomiconlocal copy offline The book on unsafe Rust. Read “FFI” and “Ownership Based Resource Management” after Stops 16 and 17.
  • Rust for Rustaceans (Jon Gjengset)EPUB · complete · offline Written for experienced programmers. Chapter 1 “Foundations” is the best single read on the memory model. Chapters 8, 10 and 11 cover async, concurrency and FFI.
  • Hands-on Rust (Herbert Wolverson)EPUB · complete · offline A game-building book. Chapter 2 is a gentle introduction to structs, vectors and enums, and Chapter 3 shows an enum-driven state machine.
  • Command-Line Rust and Systems Programming with Rust (Ken Youens-Clark)EPUB · early release, ch. 1–10 · offline These are the same book: “Systems Programming with Rust” was the early-release title. Both of your copies stop at chapter 10, so only chapters 1–10 are recommended.
  • Programming Rust, 2nd Edition (Blandy, Orendorff, Tindall)EPUB · early release, ch. 1–2 · offline Your copy contains only “Why Rust?” and “Basic Types”. “Basic Types” is still useful here: its sections on pointer types, slices and byte strings come up throughout this code.
