# The desktop platforms eth.myotis:myotis-engine-natives-<jna-prefix> is published
# for: one artifact per line, holding the Rust engine's host library at
# <jna-prefix>/<library> — the classpath path JNA loads `myotis_engine` from when
# nothing on jna.library.path has it. Read by myotis-engine-natives/build.gradle.kts
# (which publications exist), scripts/check_engine_library.sh (every line must be
# staged, built for its architecture) and engine-library.yml's host-natives
# matrix, whose legs must cover every line (the check fails a publication missing
# one).
#
